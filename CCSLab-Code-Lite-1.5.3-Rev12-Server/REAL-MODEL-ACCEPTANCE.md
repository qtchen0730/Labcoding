- UTC 时间、源码 commit、依赖 freeze 和 wheel SHA256、llama.cpp 构建版本、实际 `/v1/models` ID、模板 SHA256（不打印完整模板或私有提示）、可读的每槽 n_ctx 与槽位数；未知标为 null。
